# Slider Bank (Vanilla JS)

Коллекция кастомных слайдеров (одиночный и диапазон), написанных на чистом JavaScript без сторонних библиотек. Проект реализован в рамках изучения манипуляций с DOM, обработки событий и логики интерфейсов.

### Основной функционал
* **Типы слайдеров**: 
    * `Single Slider`: одиночное значение с динамическим градиентом полосы.
    * `Range Slider`: выбор диапазона (Min/Max) с защитой от перехлеста ползунков.
* **Управление (API)**: реализованы методы `activate`, `disable` и `enable` для контроля состояния компонентов через JS.
* **Гибкая настройка**: поддержка лимитов (min/max), шага (`step`), начальных значений и опционального отображения данных над маркером.
* **Pointer Events**: использование `setPointerCapture` обеспечивает стабильный захват ползунка на десктопах и сенсорных экранах.
* **UX/UI**: блокировка нативного Drag-and-Drop и адаптивный расчет координат относительно ширины контейнера.

### Технологический стек
* **Язык**: JavaScript (ES6+ Modules).
* **Стили**: CSS3 (Flexbox, Gradients, Absolute positioning).
* **Инструменты**: Visual Studio Code.

### Использование
```javascript
// Подключение
import { sliderBank } from './slider_bank.js';

// Одиночный слайдер
sliderBank.activate(element, 1, min, max, value, step, showValue);

// Слайдер диапазона
sliderBank.activate(element, 2, min, max, val1, val2, step);```
